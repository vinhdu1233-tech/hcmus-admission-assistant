### M2 — Backend API

### M3 — Database and Routing

- Design the initial database schema.
- Define query categories and routing logic.

### M4 — Data and Provenance

### M6 — QA and Documentation

- Identify potential failures and security risks.
- Verify acceptance criteria and documentation quality.

## 4. Collaboration Rules

1. Each task must be linked to a GitHub Issue.
2. Each member works on a separate branch.
3. Each member submits their work through a Pull Request.
4. A different team member should review changes before merging.
5. Members must record tests, limitations, and relevant evidence.
6. All official admission claims require traceable sources.
7. API keys, credentials, and private data must not be committed.
