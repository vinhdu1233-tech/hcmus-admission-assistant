# Contribution workflow
1. Choose a GitHub Issue assigned to you.
2. `git switch main && git pull && git switch -c feat/<issue-id>-<topic>`.
3. Make focused commits (`docs: ...`, `feat(ui): ...`, `test: ...`).
4. Push the branch and open a Pull Request; record what, why, how tested and AI assistance.
5. Ask a different member to review. Do not self-approve.
6. Merge approved PRs. Leader records changes in `docs/weekly-log/week01.md`.

Never commit secrets; keep factual admissions claims sourced and dated.
